# Physical-device checks

No comprehensive handheld acceptance is claimed by the automated validation. Record Android/WebView, firmware, controller mapping, installed IME and refresh rate when reporting results.

- Light/Dark/Auto/OLED, accents, OS mode changes, dialogs, favicons and focus contrast.
- Setup, inline keyboard and keyboard dismissal; rotation during entry; D-pad recovery.
- Touch/controller/mouse transitions, real hover/click, nested scrolling and Reddit loading at 60/120 Hz.
- Zero/one/many tabs, overflow, previews, end stops, touch ×, R-close, B-close and Undo.
- Bookmark collection/pinned subset/bar overflow and backup restore; remain below the documented 500-entry limit.
- Browser/context menus, Find in Page, native submenu navigation and Android Back.
- Real HTTP/authenticated/blob/data downloads, file picker, cancel/retry/offline/full storage.
- Inline/fullscreen video, audio, seeking, rotation/background and a streaming site; DRM separately.
- Private-profile separation/cleanup, media permission grant/deny and stale callbacks.
- TalkBack, font scaling, portrait/landscape, cutouts/system bars and sustained memory pressure.
