# PocketSurf 1.2.1

- A launcher start or re-entry opens and selects a fresh tab, keeping existing tabs intact. Activity recreation does not add a tab, and directly opened web links do not create an extra blank tab.
- Share and Reload remain visible on the new-tab page, dimmed and disabled instead of disappearing. Their positions remain stable, and they become usable again on a website.

This update uses the same release signing identity as 1.2.0 and installs over it without uninstalling. Existing compatibility/storage limits are unchanged.

Signed APK/App Bundle, source archive and SHA256SUMS.txt are attached.
