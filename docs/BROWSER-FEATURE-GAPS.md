# Browser feature comparison

Reviewed 2 November 2026 against the current PocketSurf source and official Android browser documentation. This is a roadmap assessment, not a promise to implement every feature. Desktop-only and iOS-only features are excluded.

PocketSurf already includes tabs/previews, bookmarks, history search, downloads, private sessions, reader view, find-in-page, sharing, custom search engines, themes, controller navigation, mouse mode and basic Custom Tabs. These are not missing features.

| Priority | Gap in PocketSurf | Browser comparison and suggested direction |
| --- | --- | --- |
| High | Complete site settings | Camera/microphone prompts exist, but no comprehensive persistent per-origin permission dashboard, location or web push integration. Add clear per-site allow/block/reset controls before extending permissions. [Firefox permissions](https://support.mozilla.org/en-US/kb/how-firefox-android-use-permissions-it-requests) |
| High | Stronger privacy protections | Current URL/cosmetic blocking supports a subset of filter syntax. It does not provide Brave's full Shields engine, fingerprint randomization or an explicit strict HTTPS upgrade mode. HTTPS URLs are already preferred for typed domains and Safe Browsing is enabled; those existing protections should not be described as absent. [Brave feature overview](https://support.brave.app/hc/en-us/articles/15872271230221-What-are-all-the-features-Brave-Browser-offers), [strict HTTPS mode](https://support.brave.app/hc/en-us/articles/15513090104717-Strict-HTTPS-Upgrade-Mode-in-Brave-Browser) |
| High | Per-site desktop mode | No desktop/mobile rendering switch or per-site user-agent preference. Useful on handhelds when a mobile layout hides controls. [Firefox Android website menu](https://support.mozilla.org/en-US/kb/explore-firefox-android-menu) |
| High | Bookmark folders and interoperable import/export | Current collection is flat and backups are PocketSurf JSON. Add folders and browser-compatible HTML import/export; address the documented 500-entry eviction behavior before scaling collections. [Firefox bookmark folders](https://support.mozilla.org/en-US/kb/add-delete-and-view-bookmarked-webpages-firefox-android) |
| Medium | Cross-device sync and send-tab | Local JSON backup is not encrypted multi-device synchronization. Scope bookmarks/open tabs first; an account or pairing architecture, conflict resolution and recovery are separate substantial work. [Firefox Sync](https://support.mozilla.org/en-US/kb/sync), [Brave features](https://brave.com/features/) |
| Medium | Integrated translation | No page translation UI or local language models. Firefox Android provides on-device translation on supported devices. A link to an online translation service would not be equivalent. [Firefox Android translation](https://support.mozilla.org/en-US/kb/android-translation) |
| Medium | Password-management UX | PocketSurf has no built-in password vault, password generation or saved-login manager. WebView is eligible for Android autofill in normal sessions; external autofill is not the same as a built-in vault and needs device acceptance testing. Prefer external credential-provider compatibility before implementing sensitive credential storage. [Brave Android password manager](https://support.brave.app/hc/en-us/articles/35784159702029-How-do-I-use-the-built-in-password-manager-in-Brave-Android) |
| Medium | Save/print page as PDF and offline reading | Downloading linked files exists; exporting the currently rendered page or storing it for offline reading does not. [Firefox Android PDF export](https://support.mozilla.org/en-US/kb/save-web-pages-pdf-firefox-android) |
| Longer term | Browser extensions | Firefox Android supports extensions; PocketSurf has no WebExtensions host. This is not a small settings addition to an Android WebView browser. [Firefox Android extensions](https://addons.mozilla.org/en-US/android/extensions/) |

Recommended order for the handheld product: site settings and reliable compatibility, bookmark organization/interoperability, privacy improvements, then PDF/translation and optional sync. Extensions are an architectural decision. Wallets, rewards and AI assistants are not required for core browser parity.

Actual website compatibility, passkey login, protected media and physical Discord integration must be checked on the installed Android/WebView combination; static source inspection does not establish support for every site.
