# PocketSurf 1.2.5

- Fix APK downloads being renamed to .bin by generic server MIME types. Preserve archive and ROM filename suffixes.
- Open APKs with the Android package installer. Installation remains subject to Android's user approval.
- Block unprompted pop-ups and open user-initiated windows in separate tabs, preserving the original page. Back returns to the opener when the new tab has no earlier history.
- Keep native requests and source-page referers for popup downloads.

Install this update using another browser if your current PocketSurf version saves it as .bin. Download affected files again after updating; existing .bin files are not automatically renamed.

Signed APK/App Bundle, source and checksums are attached. Same signing identity; direct upgrade over 1.2.x. Site-specific ad redirects cannot be verified without the exact URL.
