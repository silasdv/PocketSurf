# Contributing

Issues and pull requests are welcome. Include Android/WebView versions, orientation, refresh rate, gamepad mapping/firmware, touch/controller mode and clear reproduction steps. Remove personal URLs, credentials and account data from logs/screenshots.

Use JDK 17 and SDK 35 with the checked-in wrapper. Run Android/JVM tests, lintRelease and the navigation/cookie/generated-download JavaScript checks listed in README.md. Keep touch/controller operation equivalent, preserve contextual hints and focus, and respect font scale/reduced motion.

Native fixture images are not real WebView/device evidence; label them accordingly. Never commit keys, passwords, .local, local.properties, build caches or browser profiles. Contributions are under MIT.
